# مُعين V1

مساعد شخصي عربي قابل للتثبيت كتطبيق PWA.

## V1
- الرئيسية، اليوم، الأفكار، التقويم، ومحادثة مُعين.
- مهام ومواعيد وأفكار وتذكيرات.
- فهم أولي لعبارات عربية طبيعية.
- إدخال صوتي عندما يدعمه المتصفح.
- حفظ محلي على الجهاز عبر localStorage.
- PWA + Service Worker.

## المرحلة التالية
Firebase Authentication + Firestore + Cloud Messaging + طبقة AI متقدمة.
